# Remaining Days Pattern Fit

## Purpose
This note flags which of the remaining Day 4 through Day 12 topics fit the normal seven-brief analysis package and which ones need a deliberate adjustment.

## Pattern Reference
The default package is:
- `01` context over time
- `02` pooled historical relationship
- `03` by-year or stability check
- `04` seed-band split
- `05` archetypes or interaction layer
- `06` era comparison
- `07` current-field application
- `90` thread compiler
- `91` blog compiler

## Day-by-Day Fit
- Day 4 `Turnovers`: high fit. The only complication is offense and defense both matter, so the thread must lock one lead lens and treat the other as support.
- Day 5 `3PT Shooting`: medium-high fit. Accuracy, volume, and opponent suppression all matter, so a single-metric story will be too thin.
- Day 6 `Rebounding`: medium-high fit. Offensive and defensive rebounding should not be collapsed too early.
- Day 7 `Coaching Experience`: medium fit. This needs external coach-history data and overlaps with the coach-side layer from Day 3.
- Day 8 `Tempo`: high fit. The main risk is mistaking descriptive style for predictive value.
- Day 9 `Defense`: medium-high fit. Metric selection is the key decision because `AdjDE` is the clean lead metric but shot-quality components may sharpen the actual bracket use.
- Day 10 `Free Throw Rate`: medium fit. `FTR` and `FT%` should stay conceptually separate until the late-stage synthesis.
- Day 11 `Seeds and Upsets`: medium-low fit. This is less a single-stat analysis day and more a seed-baseline plus profile-deviation day.
- Day 12 `Favorite Teams`: low fit. This should be a synthesis day built from the prior eleven days, not a fresh seven-brief historical package.

## Operating Rule
If a day is marked below high fit, keep the folder and file naming aligned to the normal pattern but loosen the insistence on a single-metric thesis. For Day 12, use a synthesis package instead of pretending it is another standard historical study.
