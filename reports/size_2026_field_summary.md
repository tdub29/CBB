# Size Analysis 7: Projected 2026 Field vs Seed-Line Size

The March 2026 bracketology projection (`data/raw/torvik_2026/bracketology_archive/2026_expected_seeds_update.csv`) is joined to the `2026` size sample. Each team's `EFFHGT` is compared with the average of past tournament teams on the same seed line, over `2008-2025` and over `2022-2025`. This is a pre-tournament snapshot; it uses no 2026 results.

## Historical relationship (2008-2025)

- Seed-adjusted Spearman rho of `EFFHGT` with finish vs exact-seed expectation: `-0.008`.
- `EFFHGT` was positively correlated with raw finish depth in `16/17` seasons. Raw finish is not seed-adjusted.
- Seed-band rho of `EFFHGT` with finish vs the band's average, `2008-2025` / `2022-2025`: `1-2` +0.108 (n=136) / -0.054 (n=32); `3-4` -0.032 (n=136) / -0.072 (n=32); `5-6` -0.067 (n=136) / +0.015 (n=32); `7-8` -0.077 (n=136) / +0.048 (n=32); `9-10` +0.077 (n=136) / +0.053 (n=32); `11-13` +0.017 (n=204) / +0.034 (n=48); `14-16` -0.030 (n=204) / -0.305 (n=48). No significance test is applied.
